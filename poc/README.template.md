# Checked against the engine

Each pattern of the PCRE2 and php-src test suites is matched with `preg_match()` and `preg_match_all()` on many subjects, with every flag combination, and the array the engine writes is checked against the type PHPStan infers for the call. A type the engine contradicts is one PHPStan says cannot hold that array. The same scripts run on an upstream `2.3.x` checkout, where patterns are read by the parser generated by phplrt, and on this branch, where they are read by PHPRegex.

{totals}

Every contradicted pattern has one witness in `poc/witnesses/`: the pattern, the call, the subject, what the engine writes, and both types. `php poc/bin/verify.php <checkout>` replays all of them: on upstream `2.3.x` every witness is refused, on this branch every witness is accepted.

## What the generated parser reads differently

Each contradicted pattern is counted once, under the first row it matches, in the order of the table.

{families}

## Reproducing

Replay the witnesses, a few seconds each side:

```
git fetch https://github.com/phpstan/phpstan-src.git 2.3.x
git worktree add --detach ../phpstan-upstream FETCH_HEAD
composer install -d ../phpstan-upstream
php poc/bin/verify.php ../phpstan-upstream
php poc/bin/verify.php .
```

Measure a set again, a few minutes each side; once both sides are measured, `php poc/bin/report.php <out-dir>` writes the witnesses and this README from `README.template.md`:

```
php poc/bin/measure.php ../phpstan-upstream poc/data/pcre2.json.gz /tmp/poc
php poc/bin/measure.php . poc/data/pcre2.json.gz /tmp/poc
php poc/bin/report.php /tmp/poc
```

The engine decides what a pattern matches, so the witnesses hold for the PCRE2 release they were recorded with; `verify.php` skips, and names, a witness the running engine writes differently.

## The sets

- `pcre2.json.gz`: every pattern of `testdata/testinput*` of PCRE2Project/pcre2 (commit be940c4) whose modifiers PHP has, with the subject lines that follow it. One pattern is left out: `\K` inside a lookbehind makes `preg_replace_callback()` of PHP fail on the negative length of the match.
- `php-src.json.gz`: every literal pattern of a `preg_*()` call in `ext/pcre/tests` of php/php-src (branch PHP-8.6, commit 02ddcc5ee2), with the string literals of the same test.

`poc/bin/extract-suites.php` writes both from checkouts of the two projects. Subjects are added with `poc/bin/subjects.php`: samples written by the PHPRegex generator, variations of them, the literals of the pattern, random strings over its characters, and a fixed list of edge strings.

Recorded with PHP 8.4.27 and PCRE2 10.49, `pcre.jit` off, against upstream `2.3.x` at 8134126bc.
